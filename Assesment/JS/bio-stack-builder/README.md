# Creator Bio-Stack Builder

A responsive, single-page "Link-in-Bio" application that allows creators to manage their social presence, validate links, and customize their profile theme.

## Features Implemented

### ✅ Section A Concepts Covered
1. **JavaScript Execution & DOM Selection** - Populates UI dynamically after page load
2. **Conditional Logic & Verified Badge** - Shows verified badge when followers exceed 5000
3. **Arrays, Loops & Template Literals** - Efficiently renders and maintains social links
4. **LocalStorage Persistence** - Saves links, theme, and follower count
5. **Event Handling & Delegation** - Delete links without page refresh
6. **Modular JavaScript (ES6 Modules)** - Organized code with imports/exports

### ✅ Section B Tasks Completed
1. **Link Object & Input** - Form captures Title and URL as objects
2. **URL Validation** - Regex and URL constructor validation with error messages
3. **Dynamic Rendering** - Links rendered as clickable buttons opening in new tabs
4. **LocalStorage Persistence** - Array saved/loaded from localStorage
5. **Delete Action** - Remove button with instant UI and storage update

### ✅ Section C Requirements Met
1. **Dynamic Link Management** - Add/Delete social links
2. **Data Persistence** - localStorage for all user data
3. **URL Validation** - Proper URL format checking
4. **Theme Engine** - Light/Dark mode with persistence
5. **Mobile-First Design** - Responsive link-tree aesthetic
