1. WHAT IS GRAPHQL?
------------------------------------------------------------

GraphQL is a query language for APIs and also a runtime for executing those queries.

It was developed by Facebook in 2012 and released publicly in 2015.

GraphQL allows clients (frontend applications) to request exactly the data they need.

In traditional REST APIs:
- Different endpoints return fixed data.
- Sometimes you get too much data.
- Sometimes you get too little data.

GraphQL solves this problem by allowing the client to specify what data it wants.

Example:

Suppose you have a user object:

{
  id: 1,
  name: "Dennis",
  age: 21,
  email: "abc@gmail.com"
}

In REST:
You may receive all fields even if you only need the name.

In GraphQL:
You can request only the name.

Example Query:

{
  user {
    name
  }
}

Response:

{
  "data": {
    "user": {
      "name": "Dennis"
    }
  }
}

------------------------------------------------------------
2. WHY GRAPHQL WAS CREATED
------------------------------------------------------------

Problems with REST APIs:

1. Over Fetching
Getting extra unnecessary data.

2. Under Fetching
Need multiple API calls to get required data.

3. Multiple Endpoints
REST uses many endpoints.

Example:
- /users
- /posts
- /comments

GraphQL usually uses a single endpoint:

/graphql

4. Mobile Performance
GraphQL reduces unnecessary network usage.

------------------------------------------------------------
3. REST VS GRAPHQL
------------------------------------------------------------

REST:
-----
- Multiple endpoints
- Fixed response structure
- Over fetching possible
- Under fetching possible

GraphQL:
---------
- Single endpoint
- Flexible responses
- Client controls data
- Better for complex frontend apps

Example:

REST:
GET /users/1

Response:
{
  id,
  name,
  age,
  email
}

GraphQL:
Query:
{
  user(id:1){
    name
  }
}

Response:
{
  "data":{
    "user":{
      "name":"Dennis"
    }
  }
}

6. SETTING UP A GRAPHQL SERVER
------------------------------------------------------------

Install Node.js first.

Create project:

npm init -y

Install packages:

npm install express express-graphql graphql

Basic Server:

const express = require("express");
const { graphqlHTTP } = require("express-graphql");
const { buildSchema } = require("graphql");

const app = express();

const schema = buildSchema(`
  type Query {
    hello: String
  }
`);

const root = {
  hello: () => {
    return "Hello GraphQL";
  }
};

app.use("/graphql", graphqlHTTP({
  schema: schema,
  rootValue: root,
  graphiql: true
}));

app.listen(3000);

Run:

node index.js

Open:
http://localhost:3000/graphql

9. QUERIES
------------------------------------------------------------

Queries are used to FETCH data.

Example:

{
  users {
    name
    age
  }
}

Response:

{
  "data": {
    "users": [
      {
        "name": "Dennis",
        "age": 21
      }
    ]
  }
}

------------------------------------------------------------
10. MUTATIONS
------------------------------------------------------------

Mutations are used to:
- Create data
- Update data
- Delete data

Example:

mutation {
  createUser(name:"Dennis", age:21){
    id
    name
  }
}

------------------------------------------------------------
11. RESOLVERS
------------------------------------------------------------

Resolvers are functions that return data.

Example:

const root = {
  hello: () => {
    return "Hello";
  }
};

Resolver connects schema with actual data.

------------------------------------------------------------
12. ARGUMENTS
------------------------------------------------------------

Arguments allow passing values.

Example:

type Query {
  user(id: ID): User
}

Query:

{
  user(id:1){
    name
  }
}

------------------------------------------------------------
13. VARIABLES
------------------------------------------------------------

Variables make queries dynamic.

Query:

query GetUser($id: ID!) {
  user(id:$id){
    name
  }
}

Variables:

{
  "id": 1
}

------------------------------------------------------------
14. ALIASES
------------------------------------------------------------

Aliases rename query results.

Example:

{
  firstUser: user(id:1){
    name
  }

  secondUser: user(id:2){
    name
  }
}

------------------------------------------------------------
15. FRAGMENTS
------------------------------------------------------------

Fragments help reuse query parts.

Example:

fragment userFields on User {
  id
  name
}

{
  users {
    ...userFields
  }
}

------------------------------------------------------------
16. INPUT TYPES
------------------------------------------------------------

Used for mutations.

Example:

input UserInput {
  name: String
  age: Int
}

type Mutation {
  createUser(input: UserInput): User
}

25. GRAPHQL WITH NODE.JS
------------------------------------------------------------

Popular libraries:

1. graphql
2. express-graphql
3. apollo-server

Install Apollo:

npm install apollo-server graphql

Example:

const { ApolloServer, gql } = require("apollo-server");

const typeDefs = gql`
  type Query {
    hello: String
  }
`;

const resolvers = {
  Query: {
    hello: () => "Hello Apollo"
  }
};

const server = new ApolloServer({
  typeDefs,
  resolvers
});

server.listen(4000);

26. GRAPHQL WITH MONGODB
------------------------------------------------------------

Install mongoose:

npm install mongoose

Example Model:

const mongoose = require("mongoose");

const userSchema = new mongoose.Schema({
  name: String,
  age: Number
});

const User = mongoose.model("User", userSchema);

Resolver:

const resolvers = {
  Query: {
    users: async () => {
      return await User.find();
    }
  }
};
